# Blocks

One file per block: `YYYY-MM-name.md`, e.g. `2026-10-foundations.md`.
Written by `plan-training`, reviewed by `review-training`.

## Template

```markdown
# Block: <name>
Dates: <start> → <end> (<n> weeks)  ·  Phase: <A/B/C>  ·  Status: planned | active | reviewed

## Emphasis
One sentence: what this block is for and why now.

## Entry state
Weekly volume, gym frequency, Achilles status, Reactive level — each tagged.

## Running
Weekly shape, volume range, quality session, long run, strides. Ceilings, not just targets.

## Gym
Session A and B for this block: anchors, which pool exercises fill each slot, which gym.
Tier 2 fortnightly rotation for this block.

## What would change the plan
Specific triggers.

---

## Review (filled at the end)
- Planned vs done (sessions, volume, adherence %)
- Tests (training-model §12) vs previous block
- Enjoyment — did it feel good?
- Beyond-plan count, and what drove it
- Achilles trend
- Hypotheses tested — confirmed, refuted, still open
- What the next block changes
```
